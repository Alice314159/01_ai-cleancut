# AI CleanCut

语音录制与音频增强原型，使用 React + TypeScript 前端、FastAPI + SQLite 后端。

## 当前能力

- 浏览器录音，经 WebSocket 按顺序上传；支持暂停、继续、停止。离开录制页会等待最后一片音频发送并释放麦克风；异常断线后分析服务端已收到的内容。
- 会话列表和无会话时的占位页均可"导入音频"，跳过实时录制直接上传已有音频/视频文件（按内容解码，不依赖扩展名）。导入即完成终态化，与录制走同一套质量分析；解码失败按同一套语义标记失败，不生成伪造报告。
- FFmpeg 解码、真实波形、RMS/峰值/削波/噪声分析及实时质量提醒。
- 谱减法降噪，支持轻度、均衡、较强；可播放原始和增强音频。每次增强独立保存，历史版本不会被后续任务覆盖。
- 人声保护指标未通过时，结果保留供试听，输出角色继续指向此前版本。解码失败明确标记失败，不生成占位质量报告或成功指标。
- 手动标记删除区间，或复核已有候选。接受/拒绝会保存；已接受的区间可生成真实成片，支持试听与 WAV 下载。重叠区间合并后只删除一次，保护区间不可删除。
- 每次渲染独立保存源版本与决策快照。重复渲染始终使用完整时间轴的源音频；选择或音频源变化后，旧成片显示为需重新生成。
- 会话列表按创建时间倒序显示（最新在前）并标注创建时间；支持按标题/ID 搜索、按项目筛选；筛选到具体项目时显示会话数、总时长、平均时长和处理状态分布的汇总统计。新建或导入会话时可指定所属项目，最近一次使用的项目名会记住，下次默认带出。
- 会话支持重命名标题、改到另一个项目，以及彻底删除（连音频文件和全部关联记录一起清掉，需二次确认，不可恢复）。
- 录制停止或音频导入终态化成功后自动排队一次本机转写，不需要先点按钮；中文转写统一转换为简体，不受模型繁体输出倾向影响。
- 复核页可“压缩过长停顿”：按真实音频能量（相对本段底噪与语音电平自适应）找出超过阈值（1–3 秒可选）的停顿，只删中间部分、两侧保留自然间隔，作为待确认建议加入剪辑决策；底噪与语音分不开时不给建议。
- 生成成片时可选响度标准化：播客／流媒体 -16 LUFS 或广播 EBU R128 -23 LUFS。只做整体线性增益（样本数不变、字幕时间轴不受影响），受真峰值上限约束，不引入削波；达不到目标时如实显示实际响度与原因。
- 复核页支持点击起止词或直接拖选文字，词间明显停顿会标注出来且可单独选中删除；手机与电脑操作一致，选中后可直接删除。

## 本机语音转写

已接入 faster-whisper：录制或导入终态化成功后自动排队一次转写（语言选“自动识别”），不需要先点按钮；复核页仍保留“开始本机转写”，可以切中文/英文重新识别或在依赖未安装时重试。默认使用多语言 `base` 模型、CPU int8；首次下载后可离线使用，录音不上传到转写服务。没装 `faster-whisper` 时自动转写静默跳过，不影响录制/导入本身。

转写文字带起止时间。点击一个词确定起点，再点另一词扩展范围，也可直接拖选；手机和电脑使用相同操作。选好后点击“删除选中文字”直接生成删除决策。按秒数输入收在高级剪辑中，用于比转写粒度更细的裁剪。时间戳是模型估计，剪辑前需试听核对。转写成功后原子替换文字，失败保留上一次成功结果，人工剪辑选择不受重试影响。

本次开发已在 `backend/.venv` 安装依赖，模型缓存位于 `backend/data/models`。新环境准备方式：

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt -r requirements-asr.txt
python scripts/prepare_asr.py
uvicorn app.main:app --reload --port 8001
```

可通过 `CLEANCUT_ASR_MODEL` 更换模型名称或本地模型目录，通过 `CLEANCUT_ASR_MODEL_DIR` 设置缓存目录。模型准备完后设置 `CLEANCUT_ASR_OFFLINE=1` 可强制只使用本地缓存。模型实现与参数参考 [faster-whisper 官方说明](https://github.com/SYSTRAN/faster-whisper)。

## 剪辑时重录不满意的片段

在复核页选中文字后点“重录选中片段”，或在高级剪辑中输入起止时间后点“重录此时间范围”。已有剪辑也提供“重录这段”。开始重录、停止并试听，满意后点“应用重录替换”，再生成剪辑音频。

新录音按实际时长替换该段，前后内容自动衔接，不强制拉伸语速；一次最多 5 分钟、60 MB。原录音和旧成片保留，剪辑决策中可试听新录音、撤销重录，或再次录制。取消未应用的重录不会保存，麦克风会释放。

应用重录会将所选范围内已有的未拒绝剪辑改为拒绝；保护区间或部分重叠的剪辑需先处理。撤销重录恢复该段原音频，不自动恢复已被替代的旧剪辑选择。原转写和波形继续对应原始时间轴，已替换文字会标记；生成含重录的成片后自动识别成片文字，完成后可直接导出对应成片时间轴的 TXT／SRT。

## 明确的功能边界

**尚未实现实时语义识别与自动口误判断。** 随机语气词、口吃、重复提示已停用；本机离线转写在录制/导入终态化后自动排队，转写完成后可点击“生成剪辑建议”，检测相邻文字重复及少量独立语气词；所有建议默认待人工确认。复核页显示的旧候选文字不是完整转写，“确认全部待定项”保存选择；“生成剪辑音频”应用已接受的删除区间并生成 WAV。

声学复核只验证已有 repetition/stutter 候选附近是否存在相似音频，不能自行发现语义重复。音频缺失、片段越界或前文不足时不生成删除决策；通过复核仍需人工确认。

增强处理链当前只实现 `denoise`，不执行去削波或去混响；响度标准化只在生成成片时作为可选步骤执行。质量报告中的响度、真峰值、混响和人声保护指标为信号分析近似值，不能视为标准测量或声纹识别。内容分类和时钟漂移尚未测量，分别返回 `unknown` 和 `null`。

## 一键启动

在项目目录执行 `./start.sh`，也可以在 Finder 中双击 `启动 AI CleanCut.command`。
脚本可从任意工作目录调用，会检查现有依赖与 8001／5173 端口，启动前后端并等待健康检查通过。
打开 http://127.0.0.1:5173/，保持启动终端运行，按 `Ctrl+C` 同时停止两个服务。

`./start.sh --check` 仅检查依赖和端口；日志保存到 `.run/backend.log` 和 `.run/frontend.log`（每次启动覆盖）。
已有服务占用端口时会提示并退出，不会关闭其他进程。首次依赖安装仍按下方说明完成。

## 启动

系统需有 `ffmpeg`，Python 依赖建议安装在虚拟环境内。

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8001
```

另一个终端：

```bash
cd frontend
npm ci
npm run dev
```

前端默认请求 `http://127.0.0.1:8001`，可通过 `VITE_API_BASE` 覆盖。默认允许前端来源 `http://localhost:5173` 和 `http://127.0.0.1:5173`，可用逗号分隔的 `CLEANCUT_CORS_ORIGINS` 覆盖（例如换端口或局域网访问时）。

数据库与音频默认存放在 `backend/data`，可通过 `CLEANCUT_DATA_DIR` 指向其他目录。SQLite 以 WAL 模式运行并设置了忙等待，后台增强/转写与前台请求并发写入时不会因短暂锁冲突直接报错。中文转写的繁转简依赖 `zhconv`（已列入 `requirements.txt`）；未安装时转写仍会完成，只是不做转换。

1. 在会话页开始新录制，授权麦克风后开始采集；或点击"导入音频"直接上传已有文件，跳过录制。
2. 停止（或导入完成）后切换到增强页；质量报告就绪后页面自动更新。
3. 需要降噪时选择“调整音质”，增强完成后点击“继续剪辑”；音质满意可跳过此步。
4. 在复核页试听音频，输入删除区间的起止秒数（可到 0.001 秒），或接受/拒绝已有候选。
5. 也可先启动本机转写，点击文字试听并选择区间，再添加删除决策。
6. 可生成剪辑建议并试听确认，或批量拒绝待定建议。TXT / SRT 导出完整转写，字幕时间对应剪辑前录音。
7. 需要时在“压缩过长停顿”中查找并确认停顿建议；生成前可选择响度标准化目标。
8. 所有待定项处理完后点击“生成剪辑音频”，试听成片并下载 WAV。没有删除区间时可导出完整音频。

## 渲染约定

输出为 PCM 16-bit WAV，保留所选音频源的采样率和声道数；已有降噪版本本身为 16 kHz 单声道，渲染不会恢复已丢失的频率或声道。默认按选定采样边界直接拼接；可选最多 5 毫秒的删除边界淡入淡出，不改变时长。尚无交叉淡化或静音压缩。

渲染使用临时磁盘 PCM，避免整段音频驻留内存。HTTP 请求在工作线程中完成，FFmpeg 解码超时为 120 秒，尚未实现持久化渲染任务或进度百分比。禁止删除全部音频；未决策项、越界区间、保护冲突和处理中发生的源/决策变化会明确报错，原有成片保留。

## 存储与运行限制

SQLite 和音频位于 `backend/data/`。启动时会为旧增强任务表补充创建顺序字段。旧版本若在此次修复前已经共享并覆盖同一音频文件，无法从代码修复中恢复原始内容。

后台任务和单录制端限制在一个服务进程内管理；当前按单 worker、本机使用设计，尚未实现持久化任务队列、自动任务续跑、多 worker 协调或账号权限隔离。

导入音频单文件上限 300MB，一个会话只能导入一次；导入前用 ffprobe 读取原始采样率/声道数仅用于展示，不影响解码判定。

项目是自由文本的分组字段（`project_id`），没有独立的项目管理接口或校验，创建/重命名/删除都是隐式的——写了新名字就是新项目，没有会话引用的项目名也不会在筛选下拉里出现。搜索和项目统计都基于当前已加载的会话列表在前端计算，没有做服务端分页或索引，规模假设仍是本机单人使用。

目录和接口见 [后端说明](backend/README.md)，前端约定见 [前端说明](frontend/README.md)。

转写成功后会自动生成相邻文字重复的待复核提示，与转写文字一起发布；复核页显示疑似重复数量并高亮对应文字。不会自动接受或删除，已接受／拒绝的选择保持不变。当前按相邻相同文字匹配（最多 12 个词单元，整组不超过 8 秒，词间间隔不超过 1 秒），不支持跨会话或改写后的语义重复识别。语气词仍通过“查找重复与语气词”手动查找。
