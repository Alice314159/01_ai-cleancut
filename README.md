# AI CleanCut

语音录制与音频增强原型，使用 React + TypeScript 前端、FastAPI + SQLite 后端。

## 当前能力

- 浏览器录音，经 WebSocket 按顺序上传；支持暂停、继续、停止。离开录制页会等待最后一片音频发送并释放麦克风。
- 断线续传：每秒一片、带序号上传，服务端确认后才从本机删除（内存 + IndexedDB）。网络中断时录音在本机继续，自动重连（指数退避）后从服务端需要的位置补传，重复片不重写、缺片要求补传；服务端为断线会话保留 5 分钟（“重新连接中”），超时或服务重启则按已收到的内容处理。离线时按停止或页面被关闭，未上传部分留在本机，重新打开该会话会自动补传并结束（关闭页面那一刻尚在编码的不足 1 秒会丢失）。
- 会话列表和无会话时的占位页均可"导入音频"，跳过实时录制直接上传已有音频/视频文件（按内容解码，不依赖扩展名）。导入即完成终态化，与录制走同一套质量分析；解码失败按同一套语义标记失败，不生成伪造报告。
- FFmpeg 解码、真实波形、RMS/峰值/削波/噪声分析及实时质量提醒。
- 去削波（破音修复）：找出贴着削波上限、连续同号的采样段，用两侧未削波采样拟合三次曲线重建被削掉的峰，再整体降一点增益留出余量；按“采样在某个上限处堆积”判断削波，满幅以下的削波也能识别，干净音频不改动；过长的平顶段（严重失真）不处理。增强页可选“自动（检测到削波时修复）／总是尝试／不修复”，在降噪之前执行，结果显示修复处数。
- 谱减法降噪，支持轻度、均衡、较强；可播放原始和增强音频。每次增强独立保存，历史版本不会被后续任务覆盖。
- 人声保护指标未通过时，结果保留供试听，输出角色继续指向此前版本。解码失败明确标记失败，不生成占位质量报告或成功指标。
- 手动标记删除区间，或复核已有候选。接受/拒绝会保存；已接受的区间可生成真实成片，支持试听与 WAV 下载。重叠区间合并后只删除一次，保护区间不可删除。
- 每次渲染独立保存源版本与决策快照。重复渲染始终使用完整时间轴的源音频；选择或音频源变化后，旧成片显示为需重新生成。
- 会话列表按创建时间倒序显示（最新在前）并标注创建时间，有封面的会话显示封面缩略图；支持按标题/ID 搜索、按项目筛选；筛选到具体项目时显示会话数、总时长、平均时长和处理状态分布的汇总统计。新建或导入会话时可指定所属项目，最近一次使用的项目名会记住，下次默认带出。
- 会话支持重命名标题、改到另一个项目，以及彻底删除（连音频文件和全部关联记录一起清掉，需二次确认，不可恢复）。
- 录制停止或音频导入终态化成功后自动排队一次本机转写，不需要先点按钮；中文转写统一转换为简体，不受模型繁体输出倾向影响。
- 复核页可“压缩过长停顿”：按真实音频能量（相对本段底噪与语音电平自适应）找出超过阈值（1–3 秒可选）的停顿，只删中间部分、两侧保留自然间隔，作为待确认建议加入剪辑决策；底噪与语音分不开时不给建议。
- 生成成片时可选响度标准化：播客／流媒体 -16 LUFS 或广播 EBU R128 -23 LUFS。只做整体线性增益（样本数不变、字幕时间轴不受影响），受真峰值上限约束，不引入削波；达不到目标时如实显示实际响度与原因。
- 成片可直接导出 MP3 或 M4A（AAC），码率 96–320 kbps 可选（默认 192）。文件名取会话标题，写入标题元数据；转码结果按版本缓存，重复下载不重新编码，删除会话时一并清理。需本机 ffmpeg 带 `libmp3lame`／`aac` 编码器，缺失时会提示。
- 节目封面：在“生成与导出”中上传 JPEG／PNG／WebP（5MB 以内），自动转为长边不超过 1400 像素的 JPEG 并去掉原图元数据，导出 MP3／M4A 时作为封面写入。会话标题可在剪辑导出页直接重命名，同时用作导出文件名和音频标题；改标题、章节或封面后导出会自动重新生成。
- 撤销／重做：删除选中、按秒删除、接受／拒绝、确认全部、拒绝待定建议、查找重复与语气词、查找过长停顿都可撤销（最近 50 步），操作后底部提示条可一键撤销。撤销在服务端一次性核对修订号，若期间被别处修改则整体拒绝并刷新，不会覆盖他人改动；保存重录也算一步（撤销会删除重录决策并恢复被它替代的剪辑，重做按原编号重建）；手动刷新数据后撤销记录清空。
- 手机端剪辑：选中文字后在底部导航上方出现固定操作栏（删除／试听／重录／章节／取消），不遮挡正在选择的文字；转写行高与点击区域加大（每个词至少约 50 像素高），选中范围显示为连续高亮。
- 剪辑快捷键（电脑）：空格 播放／暂停，Delete 删除选中文字，Esc 取消选择，Ctrl／⌘+Z 撤销，Ctrl／⌘+Shift+Z（或 Ctrl+Y）重做；在输入框中不生效。
- 章节标记：在转写中选中一句点“设为章节”，或在播放位置添加；章节标在剪辑前的时间上，可改名、删除，转写正文中按章节分段显示。导出成片时按该成片的删除／重录快照自动换算时间（起点被剪掉的章节挪到剪切处，被剪光的章节合并），并写入 MP3／M4A 的章节信息；也可复制“00:00 标题”格式的章节列表贴到节目简介。
- 复核页支持点击起止词或直接拖选文字，词间明显停顿会标注出来且可单独选中删除；手机与电脑操作一致，选中后可直接删除。

## 本机语音转写

已接入 faster-whisper：录制或导入终态化成功后自动排队一次转写（语言选“自动识别”），不需要先点按钮；复核页仍保留“开始本机转写”，可以切中文/英文重新识别或在依赖未安装时重试。默认使用多语言 `base` 模型、CPU int8；首次下载后可离线使用，录音不上传到转写服务。没装 `faster-whisper` 时自动转写静默跳过，不影响录制/导入本身。

转写文字带起止时间。点击一个词确定起点，再点另一词扩展范围，也可直接拖选；手机和电脑使用相同操作。选好后点击“删除选中文字”直接生成删除决策。按秒数输入收在高级剪辑中，用于比转写粒度更细的裁剪。时间戳是模型估计，剪辑前需试听核对。转写成功后原子替换文字，失败保留上一次成功结果，人工剪辑选择不受重试影响。

本次开发已在 `backend/.venv` 安装依赖，模型缓存位于 `backend/data/models`。新环境准备方式：

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt -r requirements-asr.txt
python scripts/prepare_asr.py
uvicorn app.main:app --reload --port 8001
```

可通过 `CLEANCUT_ASR_MODEL` 更换模型名称或本地模型目录，通过 `CLEANCUT_ASR_MODEL_DIR` 设置缓存目录。模型准备完后设置 `CLEANCUT_ASR_OFFLINE=1` 可强制只使用本地缓存。模型实现与参数参考 [faster-whisper 官方说明](https://github.com/SYSTRAN/faster-whisper)。

## 剪辑时重录不满意的片段

在复核页选中文字后点“重录选中片段”，或在高级剪辑中输入起止时间后点“重录此时间范围”。已有剪辑也提供“重录这段”。开始重录、停止并试听，满意后点“应用重录替换”，再生成剪辑音频。

新录音按实际时长替换该段，前后内容自动衔接，不强制拉伸语速；一次最多 5 分钟、60 MB。原录音和旧成片保留，剪辑决策中可试听新录音、撤销重录，或再次录制。取消未应用的重录不会保存，麦克风会释放。

应用重录会将所选范围内已有的未拒绝剪辑改为拒绝；保护区间或部分重叠的剪辑需先处理。撤销重录恢复该段原音频，不自动恢复已被替代的旧剪辑选择。原转写和波形继续对应原始时间轴，已替换文字会标记；生成含重录的成片后自动识别成片文字，完成后可直接导出对应成片时间轴的 TXT／SRT。

## 明确的功能边界

**尚未实现录制过程中的实时语义识别。** 录制中的实时语气词、口吃、重复提示已停用；本机离线转写在录制/导入终态化后自动排队，转写完成后自动提示相邻文字重复与口吃（词首重复如“我 我们”“th- the”，词内首字重复如“这这个”，排除常见叠词；词内边界按字数估算），并可手动查找独立语气词；所有建议默认待人工确认。复核页显示的旧候选文字不是完整转写，“确认全部待定项”保存选择；“生成剪辑音频”应用已接受的删除区间并生成 WAV。

声学复核只验证已有 repetition/stutter 候选附近是否存在相似音频，不能自行发现语义重复。音频缺失、片段越界或前文不足时不生成删除决策；通过复核仍需人工确认。

增强处理链当前实现去削波（`declip`）、减轻混响（`dereverb`，可选、默认关闭）与降噪（`denoise`）；减轻混响用晚期混响谱抑制，先从声音停下后的衰减估计混响时间（粗估，误差约 ±40%，估不出按 0.5 秒），只能减轻不能去净，早期反射不处理；质量报告的“混响”标记改为按估计的混响时间 ≥0.6 秒判断；响度标准化只在生成成片时作为可选步骤执行。质量报告中的响度、真峰值、混响和人声保护指标为信号分析近似值，不能视为标准测量或声纹识别。素材类型按信号特征粗分为无人声／音乐为主／人声＋背景音乐／人声（音量是否按音节节奏大幅起伏、频谱 0.3 秒后是否基本不变、停顿处的背景是乐音还是噪声），拿不准时为“未确定”，不区分单人与多人；长录音只抽取三段各 20 秒分析。录音时钟偏差：浏览器累计实际录音时长（扣除暂停），停止时报告给服务端，与解码采样数比较得出偏差（ppm），在录制页“录音时钟”显示；只对 30 秒以上、正常停止的录音测量（浏览器启停本身有约 0.1–0.2 秒误差），可发现采样率错配这类百分比级问题，偏差超过 2% 时提示，不改写音频；细微的晶振漂移测不出。

## 一键启动

在项目目录执行 `./start.sh`，也可以在 Finder 中双击 `启动 AI CleanCut.command`。
脚本可从任意工作目录调用，会检查现有依赖与 8001／5173 端口，启动前后端并等待健康检查通过。
打开 http://127.0.0.1:5173/，保持启动终端运行，按 `Ctrl+C` 同时停止两个服务。

`./start.sh --check` 仅检查依赖和端口；日志保存到 `.run/backend.log` 和 `.run/frontend.log`（每次启动覆盖）。
已有服务占用端口时会提示并退出，不会关闭其他进程。首次依赖安装仍按下方说明完成。

## 安卓 App（GitHub 自动打包）

`frontend/` 用 Capacitor 包装成安卓 App，GitHub Actions 自动编译 APK（`.github/workflows/android-apk.yml`）：前端有改动推送时自动运行，也可以在 GitHub 的 **Actions → Android APK → Run workflow** 手动运行。完成后在该次运行页面底部的 **Artifacts** 下载 `cleancut-android-apk`，解压得到 `app-debug.apk`，传到手机安装（需允许“安装未知来源应用”）。

- APK 使用仓库里固定的调试签名（`frontend/android/app/debug.keystore`，标准调试口令，仅供测试安装，不能上架应用商店），版本号随运行次数递增，新版可直接覆盖安装。
- App 首次打开选择 **连接电脑** 或 **先看演示**。连接电脑：在电脑上运行 `./start.sh --app`，把终端显示的“App 连接地址”（如 `192.168.1.23:8001`）填进 App；转写、降噪、剪辑仍在电脑上完成，手机负责录音、试听和剪辑操作，首次录音时系统会请求麦克风权限。
- `--app` 模式下后端在局域网 8001 端口无需登录即可访问，并允许 App 跨域访问，只在家里／办公室等可信网络中使用。电脑防火墙需允许 8001 端口入站。
- 顶栏“切换连接”可改填地址或改用演示模式。

### 在电脑上测试 App

- **安卓模拟器（最接近真机）**：安装 Android Studio，在 Device Manager 里创建一台模拟器并启动，把 `app-debug.apk` 拖进模拟器窗口安装。电脑上运行 `./start.sh --app`，App 连接页填 `10.0.2.2:8001`（模拟器访问电脑本机的固定地址）。录音前在模拟器的 Extended Controls → Microphone 打开“Virtual microphone uses host audio input”，模拟器才能用电脑的麦克风。
- **电脑浏览器（不装安卓工具）**：一个终端运行 `./start.sh --app`，另一个终端 `cd frontend && npm run preview:app`，浏览器打开 http://127.0.0.1:4173/ ，连接页填 `127.0.0.1:8001`。看到的是 App 内同一套页面（连接页、演示、切换连接）；开发者工具切到手机尺寸更接近真机。它验证不了安卓特有的部分（安装、麦克风权限弹窗、图标与启动画面）。

本地构建 App 版网页：`cd frontend && npm run build:app && npx cap sync android`；有安卓 SDK 时可在 `frontend/android` 运行 `./gradlew assembleDebug`。

## 在手机上测试

转写、剪辑、导出都在电脑上的后端完成；手机通过同一个 Wi-Fi 访问电脑上的服务，可以“添加到主屏幕”，之后像 App 一样从桌面打开。

```bash
./start.sh --lan
```

1. 终端会打印手机访问地址，例如 `https://192.168.1.23:5173/`（多网卡时可用 `CLEANCUT_LAN_IP=192.168.x.x ./start.sh --lan` 指定）。手机连同一个 Wi-Fi 后在浏览器打开。
2. 首次会提示证书不受信任：这是脚本在本机生成的自签名证书（保存在 `.run/lan-cert`，IP 变化时自动重新生成）。Android Chrome 点“高级 → 继续前往”；iPhone Safari 点“显示详细信息 → 访问此网站”。之所以用 HTTPS，是因为手机浏览器只在 HTTPS 下允许麦克风录音。
3. 添加到主屏幕：Android Chrome 菜单 →“添加到主屏幕”；iPhone Safari 分享 →“添加到主屏幕”。从桌面打开时全屏显示，没有浏览器地址栏。

手机只连前端地址，`/api` 与 `/ws` 由前端服务转发给只监听 `127.0.0.1` 的后端，后端不直接暴露在局域网上。电脑防火墙需允许 5173 端口的入站连接。证书未被系统信任时浏览器不会启用离线缓存，不影响正常使用；如需去掉警告，可把 `.run/lan-cert/cert.pem` 安装为手机的受信任证书。

只想看界面、不连后端时，可用演示构建（见 `frontend/README.md`）。

## 启动

系统需有 `ffmpeg`，Python 依赖建议安装在虚拟环境内。

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8001
```

另一个终端：

```bash
cd frontend
npm ci
npm run dev
```

前端默认请求 `http://127.0.0.1:8001`，可通过 `VITE_API_BASE` 覆盖。默认允许前端来源 `http://localhost:5173` 和 `http://127.0.0.1:5173`，可用逗号分隔的 `CLEANCUT_CORS_ORIGINS` 覆盖（例如换端口或局域网访问时）。

数据库与音频默认存放在 `backend/data`，可通过 `CLEANCUT_DATA_DIR` 指向其他目录。SQLite 以 WAL 模式运行并设置了忙等待，后台增强/转写与前台请求并发写入时不会因短暂锁冲突直接报错。中文转写的繁转简依赖 `zhconv`（已列入 `requirements.txt`）；未安装时转写仍会完成，只是不做转换。

1. 在会话页开始新录制，授权麦克风后开始采集；或点击"导入音频"直接上传已有文件，跳过录制。
2. 停止（或导入完成）后切换到增强页；质量报告就绪后页面自动更新。
3. 需要降噪时选择“调整音质”，增强完成后点击“继续剪辑”；音质满意可跳过此步。
4. 在复核页试听音频，输入删除区间的起止秒数（可到 0.001 秒），或接受/拒绝已有候选。
5. 也可先启动本机转写，点击文字试听并选择区间，再添加删除决策。
6. 可生成剪辑建议并试听确认，或批量拒绝待定建议。TXT / SRT 导出完整转写，字幕时间对应剪辑前录音。
7. 需要时在“压缩过长停顿”中查找并确认停顿建议；生成前可选择响度标准化目标。
8. 所有待定项处理完后点击“生成剪辑音频”，试听成片并下载 WAV，或选择码率后下载 MP3／M4A。没有删除区间时可导出完整音频。

## 渲染约定

输出为 PCM 16-bit WAV，保留所选音频源的采样率和声道数；已有降噪版本本身为 16 kHz 单声道，渲染不会恢复已丢失的频率或声道。默认按选定采样边界直接拼接；可选最多 5 毫秒的删除边界淡入淡出，不改变时长。尚无交叉淡化或静音压缩。

渲染使用临时磁盘 PCM，避免整段音频驻留内存。HTTP 请求在工作线程中完成，FFmpeg 解码超时为 120 秒，尚未实现持久化渲染任务或进度百分比。禁止删除全部音频；未决策项、越界区间、保护冲突和处理中发生的源/决策变化会明确报错，原有成片保留。

## 存储与运行限制

SQLite 和音频位于 `backend/data/`。启动时会为旧增强任务表补充创建顺序字段。旧版本若在此次修复前已经共享并覆盖同一音频文件，无法从代码修复中恢复原始内容。

后台任务和单录制端限制在一个服务进程内管理；当前按单 worker、本机使用设计，尚未实现持久化任务队列、自动任务续跑、多 worker 协调或账号权限隔离。

导入音频单文件上限 300MB，一个会话只能导入一次；导入前用 ffprobe 读取原始采样率/声道数仅用于展示，不影响解码判定。

项目是自由文本的分组字段（`project_id`），没有独立的项目管理接口或校验，创建/重命名/删除都是隐式的——写了新名字就是新项目，没有会话引用的项目名也不会在筛选下拉里出现。搜索和项目统计都基于当前已加载的会话列表在前端计算，没有做服务端分页或索引，规模假设仍是本机单人使用。

目录和接口见 [后端说明](backend/README.md)，前端约定见 [前端说明](frontend/README.md)。

转写成功后会自动生成相邻文字重复的待复核提示，与转写文字一起发布；复核页显示疑似重复数量并高亮对应文字。不会自动接受或删除，已接受／拒绝的选择保持不变。当前按相邻相同文字匹配（最多 12 个词单元，整组不超过 8 秒，词间间隔不超过 1 秒），不支持跨会话或改写后的语义重复识别。语气词仍通过“查找重复与语气词”手动查找。
